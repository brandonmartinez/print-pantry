# Print Pantry

A cozy home for 3D print files: browse a model library, pick a project, and
queue a print request.

Print Pantry is a planned self-hosted application with a React/Vite frontend,
a Node.js backend, and PostgreSQL. A NAS holds the model library and runs the
containers. Files remain usable outside the app; print requests never
automatically start a printer.

See [KICKOFF.md](KICKOFF.md) for the initial product and implementation brief.

No application code has been implemented yet. No open-source license has been
selected yet.
